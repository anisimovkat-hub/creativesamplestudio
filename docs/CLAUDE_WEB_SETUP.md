# Как загрузить проект CSS в Claude

Для лендингов лучше использовать Claude Code: он открывает весь репозиторий, видит `CLAUDE.md` и проектные skills, а изменения остаются в рабочей ветке.

Обычный проект в Claude.ai тоже подойдёт для черновика, но публикацию и перенос файлов в GitHub придётся делать отдельно.

## Вариант 1. Claude Code — рекомендуемый

1. Скачайте или клонируйте репозиторий `anisimovkat-hub/creativesamplestudio`.
2. Откройте корневую папку репозитория в Claude Code.
3. Убедитесь, что на месте `CLAUDE.md` и папка `.claude/skills/`.
4. Создайте ветку `smm/<slug>`.
5. Начните с команды:

> Используй /find-css-materials, /css-brand и /create-css-landing. Для изображений используй /prepare-css-assets. После сборки запусти /review-css-landing.

Skills отдельно загружать не нужно: Claude Code читает их из репозитория.

## Вариант 2. Обычный Claude Project

Создайте отдельный Project и загрузите в его знания:

- `CLAUDE.md`;
- `.claude/skills/css-brand/SKILL.md`;
- `.claude/skills/find-css-materials/SKILL.md`;
- `.claude/skills/prepare-css-assets/SKILL.md`;
- `.claude/skills/create-css-landing/SKILL.md`;
- `.claude/skills/review-css-landing/SKILL.md`;
- `docs/SMM_CLAUDE_ONBOARDING.md`;
- текущий утверждённый бриф.

В обычном Claude Project команды со слешем могут не работать как команды Claude Code. В таком случае напишите: «Следуй инструкции из файла find-css-materials/SKILL.md», а затем назовите остальные нужные файлы.

## Как передать изображения

Не загружайте в Claude всю медиатеку.

Для одного лендинга достаточно:

- утверждённого брифа;
- выбранных фотографий;
- готового текста или документа с текстом;
- нужного PDF, если он будет скачиваться со страницы;
- ссылки на референсный лендинг.

Для каждого файла напишите, где он используется: «hero», «секция о команде», «фон блока», «PDF после регистрации». Так Claude не будет угадывать.

## Где искать материалы

Сначала используйте `/find-css-materials`. Точные ссылки на частные папки Google Drive находятся в документе «CSS — бренд и создание лендингов в Claude», который открыт Юлии отдельно.

Не вставляйте частные ссылки Drive в публичный GitHub и не используйте их напрямую в HTML.

## Что должно вернуться в GitHub

Готовая страница хранится в:

`public/<slug>/index.html`

Материалы страницы — в:

`public/<slug>/assets/`

Перед публикацией откройте pull request и приложите мобильный и десктопный скриншоты. Сливать изменения в `main` самостоятельно не нужно.
