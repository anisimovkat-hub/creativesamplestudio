# Карта репозитория Creative Sample Studio

Эта карта помогает быстро понять, что можно использовать для нового лендинга.

## Основные файлы

- `CLAUDE.md` — постоянные правила проекта.
- `.claude/skills/` — skills для Claude Code.
- `public/` — всё, что может попасть на публичный сайт.
- `functions/` — backend и обработка форм; без отдельного задания не менять.
- `integrations/` — внешние интеграции; без отдельного задания не менять.
- `wrangler.toml` — настройки Cloudflare; без отдельного задания не менять.

## Живые страницы

- `public/webinar/` — лендинг вебинара, форма и семь локальных фотографий.
- `public/discovery-call/` — компактный лендинг консультации.
- `public/market-analysis/` — внутренняя аналитическая страница. Не использовать как рекламный текст или шаблон нового лендинга.

## Где создавать новую страницу

```
public/<slug>/
  index.html
  assets/
```

Новая страница не должна перезаписывать существующий маршрут.

## Что можно переиспользовать

- визуальные принципы из действующих страниц;
- цветовую и типографическую систему из `/css-brand`;
- фотографии из `public/webinar/assets/`, если они подходят по смыслу и утверждены для нового размещения;
- готовые доступные компоненты без копирования старых дат, форм и согласий.

## Чего в репозитории сейчас нет

- отдельного утверждённого файла логотипа;
- общей публичной фототеки;
- универсальной формы, которую можно без проверки ставить на любой лендинг.

Для логотипа используйте существующий текстовый wordmark или запросите утверждённый файл. Материалы из частной фототеки выбираются через приватную карту Google Drive.
