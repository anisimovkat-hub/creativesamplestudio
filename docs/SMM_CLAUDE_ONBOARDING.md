# Как Юлии создавать лендинги CSS через Claude

Этот проект подготовлен так, чтобы Claude Code видел правила бренда и рабочий процесс сразу после открытия репозитория. Отдельно загружать инструкции в каждый чат не нужно: они лежат в `CLAUDE.md` и `.claude/skills/`.

## Что понадобится один раз

1. Аккаунт GitHub.
2. Установленный Claude Code и доступ к нему.
3. Репозиторий `anisimovkat-hub/creativesamplestudio`.
4. Доступ на создание веток или, если доступа пока нет, собственный fork репозитория.

Cloudflare, Google Sheets с лидами и секретные ключи для обычной работы с лендингами не нужны.

## Как начать новый лендинг

Открой папку проекта в Claude Code и дай ему задачу примерно в таком виде:

> Используй /css-brand и /create-css-landing. Создай новый лендинг Creative Sample Studio для [цель и аудитория]. Slug: [адрес страницы]. Вот утверждённый текст и материалы: [ссылка или файлы]. Не меняй существующие страницы и служебные файлы. После сборки используй /review-css-landing и подготовь pull request для Кати.

Чем точнее исходный бриф, тем меньше Claude будет задавать уточняющих вопросов.

## Как устроена публикация

- Каждый лендинг живёт в своей папке: `public/<slug>/index.html`.
- Работа идёт в отдельной ветке `smm/<slug>`.
- Юлия открывает pull request, прикладывает мобильный и десктопный скриншоты.
- Катя проверяет изменения и принимает их.
- После принятия страница публикуется на общем домене по адресу `https://creativesamplestudio.pages.dev/<slug>/`.

Самостоятельно объединять изменения с `main` не нужно.

## Что нельзя передавать Claude и добавлять в GitHub

- пароли и ключи;
- токены Cloudflare и Google;
- выгрузки лидов;
- телефоны и email участников;
- внутренние таблицы;
- данные из форм регистрации.

Юлия не должна менять `functions/`, `integrations/`, `wrangler.toml`, настройки заголовков и редиректов без отдельного задания Кати.

## Формы и согласия

Форму нельзя считать подключённой только потому, что она выглядит как существующая.

В pull request нужно явно написать:

- какие данные собираются;
- куда они отправляются;
- есть ли согласие на email;
- есть ли отдельное согласие на WhatsApp.

Поле с номером телефона само по себе не означает согласие на связь через WhatsApp.

## Быстрые команды для Claude

- `/css-brand` — применить бренд-систему CSS;
- `/create-css-landing` — собрать новый лендинг безопасным способом;
- `/review-css-landing` — проверить страницу перед передачей Кате.

Если Claude предлагает поменять backend, деплой, форму регистрации или секреты, работу нужно остановить и согласовать это с Катей.
