# Диаграммы обзора CSS

Проверка источников: 16 сентября 2026. Исходный интерактивный отчёт не изменён.

Сохранены только небольшой снимок проверенных данных и авторские компоненты. Зависимости и сборка не входят в репозиторий.

- `snapshot.json`: 4 набора, единицы и ссылки. Индекс запасов 100 → 114 — пересчёт опубликованного изменения +14%, не фактическое число дней.
- `ReportContent.jsx` и `report.css`: диаграммы через штатный React/Recharts-рендерер Data.
- Финальные PNG: `public/market-analysis/assets/`, 4 настольные диаграммы и 2 мобильные (ожидания / запасы). Для покупателей и консультаций на мобильном экране показаны компактные HTML-таблицы с теми же проверенными значениями: 80% / 70%, £50 + НДС / £125. Экспорт обновлённых мобильных картинок прервали зависания браузера; неточными прежними картинками они не подменены.

Для воспроизведения подготовить временный пустой Data report из `snapshot.json` через установленный `prepare-data-app.mjs --surface report --blank`, прочитать его AGENTS.md, заменить только авторский ReportContent и добавить report.css. Перед экспортом установить buildStatus=complete и собрать штатным data-app.mjs build --separate-data.

PNG экспортированы встроенным Export chart → Original → Download PNG при ширине браузера 1470 и 390. Включены заголовок, описание и значения; отключены технические подписи осей и встроенный источник. Русские пояснения, ссылки и ограничения находятся рядом с диаграммами на странице.

Ожидания 2025/2026 — разные опросы, не итоговые продажи; потребительские доли не складываются. £87,50 — среднее 2 опубликованных базовых UK-часовых тарифов, не средний оплаченный чек или готовность платить. НДС и состав услуг указаны на странице.
