# Creative Sample Studio brand system

Use this skill before designing or rewriting any CSS landing page.

## Brand character

Creative Sample Studio should feel editorial, confident, modern, and useful. It is for creative professionals, so the design can be distinctive without becoming decorative or noisy.

The writing should sound like an experienced creative partner: direct, warm, concrete, and free of inflated marketing language.

## Core visual tokens

- Primary navy: `#262C9E`
- Deep navy: `#1C2170`
- Light neutral: `#F4F5F7`
- Near black: `#111114`
- White: `#FFFFFF`
- Fine navy divider: `rgba(38, 44, 158, 0.15)`

Use navy as the anchor, neutral space to create rhythm, and black for readable body copy. Avoid introducing an unrelated accent color without approval.

## Typography

- Body: Inter.
- Display/headings: Helvetica Neue, Helvetica, Arial, sans-serif.
- Headlines can be uppercase and tightly composed.
- Use a clear scale and strong contrast between display type and body copy.
- Keep paragraph width readable; do not fill the screen with long centered text.

## Layout and components

- Prefer a sharp editorial grid, generous whitespace, and visible hierarchy.
- Corners should be restrained; the current system generally uses a `2px` radius.
- Buttons should be clear and decisive, with visible hover and keyboard-focus states.
- Use thin dividers and large type instead of card overload.
- Alternate navy, white, and light-neutral sections with intention.
- Photography should feel authentic and editorial. Existing pages often use grayscale treatment.
- Motion should clarify hierarchy, not delay access to content.

## Copy principles

- State the offer and audience early.
- Use specifics instead of superlatives.
- Keep sentences natural and varied.
- Avoid “unlock”, “revolutionary”, “game-changing”, “seamless”, and other generic AI/marketing phrases.
- Never create fake urgency, fake scarcity, unapproved proof, or unverified claims.
- Preserve approved facts exactly.
